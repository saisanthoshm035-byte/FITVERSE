   "scrolls itself back to the top" glitch — SAVED CHATS sidebar, AI chat,

   position before the repaint and restores it right after. Verified:
   scroll to 100 → refresh fires → still 100.

   pins the chat to the newest message (as before). Quiet background
   refreshes no longer yank you to the bottom while you're reading an
   older message (within ~140px of the bottom it still follows along).

   person at the same moment used to create two separate threads (the
   server checked-then-created without a lock). The find-or-create is now
   serialized, and every existing duplicate pair in the database is merged
   at boot (messages, read markers and unread notifications are kept and
   re-pointed to the one surviving thread). Verified with 3 parallel API
   sends → all landed in ONE thread.
